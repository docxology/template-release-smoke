# template-release-smoke

Public integration smoke-test repository for the [docxology/template](https://github.com/docxology/template) unified release orchestrator (`scripts/publish/publish_project_release.py`).

## Purpose

This repository exists only to validate end-to-end GitHub release creation and asset upload during automated publishing tests. Releases attach rendered manuscript PDFs from the template workspace; they do not mirror template source code.

**Do not cite** releases or Zenodo records created from this smoke test.
