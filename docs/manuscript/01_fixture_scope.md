# Fixture scope

The GitHub repository provides the remote release endpoint. The template workspace supplies the orchestrator and the PDF to upload. This arrangement exercises the interaction between the orchestrator and GitHub while keeping the endpoint independent of the template source tree. The upstream publishing guide documents the target repository, release tags, PDF checksums, and GitHub–Zenodo cross-link checks [@templatePublishingGuide].

The fixture releases and any associated Zenodo deposits are test artifacts. They should not be cited as research outputs.
