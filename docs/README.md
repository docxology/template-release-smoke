# Release smoke-test documentation

The template release orchestrator uses this repository as a real GitHub endpoint for testing tag and release creation and upload of a PDF rendered in the template workspace. The orchestrator and publishing settings live in [docxology/template](https://github.com/docxology/template/blob/87704feae0a4490ef7dad9c931d268e8c30273c2/docs/guides/publishing-guide.md). Releases and Zenodo records associated with this test are test artifacts and should never be cited.
